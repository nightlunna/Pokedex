# Pokédex

Aplicação que exibe uma lista de Pokémons utilizando dados de uma API pública.
O projeto permite visualizar diferentes Pokémons e também pesquisar por um Pokémon específico através de uma barra de busca.

## Funcionalidades

* Listagem de Pokémons obtidos de uma API
* Pesquisa de Pokémon pelo nome
* Exibição dinâmica das informações dos Pokémons
* nterface simples e interativa

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Consumo de API
